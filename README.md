# FastAPI Template Setup

## Prerequisites

Install the following before setting up the project:

- **Python** — version specified in `pyproject.toml`
- **uv** — Python package and project manager by Astral
- **Git**
- **MySQL** — or the database configured for this project

## 1. Clone the Repository

```bash
git clone https://github.com/Feyded/template-fastapi.git
cd template-fastapi
```

## 2. Install uv

If you haven't installed uv yet, follow the official instructions:

https://docs.astral.sh/uv/getting-started/installation/

Verify the installation:

```bash
uv --version
```

## 3. Install Dependencies

```bash
uv sync
```

This creates a virtual environment and installs the dependencies recorded in `uv.lock`.

## 4. Configure Environment Variables

Copy the example environment file:

**Windows (PowerShell):**

```powershell
Copy-Item .env.example .env
```

**Linux/macOS:**

```bash
cp .env.example .env
```

Update `.env` with your local configuration:

```env
SECRET_KEY=replace-with-a-secret-key
DATABASE_URL=mysql+pymysql://username:password@localhost:3306/database_name
COOKIE_SECURE=false
```

Replace the database credentials with your actual values. Ensure the database exists before running migrations.

Generate a secret key if needed:

```bash
uv run python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Copy the generated value into `SECRET_KEY`.

## 5. Run Database Migrations

```bash
uv run alembic upgrade head
```

This applies all existing database migrations.

## 6. Start the Development Server

```bash
uv run python -m fastapi dev src/my_fastapi_app/main.py
```

Replace the file path with the actual location of your FastAPI application's `main.py`.

Open the API documentation:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Useful Commands

| Command                                                             | Purpose                      |
| ------------------------------------------------------------------- | ---------------------------- |
| `uv sync`                                                           | Install project dependencies |
| `uv add package-name`                                               | Add a dependency             |
| `uv remove package-name`                                            | Remove a dependency          |
| `uv run python -m fastapi dev src/my_fastapi_app/main.py`           | Start the development server |
| `uv run python -m fastapi run src/my_fastapi_app/main.py`           | Start the production server  |
| `uv run python -m alembic upgrade head`                             | Apply database migrations    |
| `uv run python -m alembic revision --autogenerate -m "description"` | Generate a migration         |
| `uv lock`                                                           | Update the lockfile          |

## Notes

- Do not commit `.env` or other files containing secrets.
- Keep `.env.example` updated whenever required environment variables change, but never include real credentials.
- Commit both `pyproject.toml` and `uv.lock` so other developers can install consistent dependency versions.
- Review autogenerated migrations before applying them.
- Use `COOKIE_SECURE=true` when deploying over HTTPS.
